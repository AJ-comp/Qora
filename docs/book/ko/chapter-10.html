10장. Qora 코드는 어떻게 읽을까?

마지막으로, 앞으로 자주 보게 될 Qora 코드의 기본 모양을 함께 살펴볼게요.
Qora 코드는 양자 상태를 직접 눈으로 보여 주는 표기법은 아니지만, 어떤 큐비트에 어떤 게이트를 어떤 순서로 적용하는지 명확하게 적어줘요.
그래서 수학적으로는 상태 벡터에 유니터리 변환을 차례대로 적용하는 회로 설명으로 읽을 수 있어요.

Qora에서는 양자 작업을 operation으로 적어요. 그중 Main이라는 이름의 operation이 프로그램이 시작되는 곳, 즉 진입점이에요.
이건 관례가 아니라 언어 규칙이에요. 그래서 Main은 매개변수를 가질 수 없고, 다른 곳에서 호출할 수도 없어요.

기본 형태

가장 작은 Qora 프로그램부터 보자

operation Main() {
    // 여기에 실행할 양자 회로 작성
}

큐비트 준비하기

큐비트 준비는 use로 시작해요.

use q = Qubit[1];

이 코드는 큐비트 하나를 준비한 뒤, 그 큐비트 묶음에 q라는 이름을 붙여요.
Qubit[1]은 큐비트가 한 개라는 뜻이고, 그 큐비트는 q[0]으로 가리켜요.
이 책의 예제를 실행하는 시뮬레이터는 새로 준비한 큐비트를 계산 기저 상태 |0⟩에서 시작해요. 그래서 이 책에서는 새로 준비한 큐비트가 |0⟩에서 시작한다고 읽을게요.
다만 Qora가 만들어 내는 OpenQASM 3의 명세 자체는 새 큐비트의 초기 상태를 정해 두지 않아요. 어떤 실행 환경에서도 확실히 |0⟩에서 시작하게 하려면 Reset(q[0]);처럼 초기화하는 방법이 있어요.

게이트 적용하기

게이트는 함수 호출처럼 적어주면 돼요.

H(q[0]);

이 코드는 q[0]에 H 게이트를 적용하는 줄이에요.
수학적으로는 현재 상태 벡터에 H 행렬을 곱하는 단계예요.
X 게이트는 X(q[0]);처럼, 두 큐비트 게이트인 CNOT은 CNOT(q[0], q[1]);처럼 쓰면 돼요.

측정하기

측정에는 M을 써요.

var result: bit = M(q[0]);

이 줄은 q[0]을 측정하고, 그 결과를 고전 비트 result에 저장해요.
측정하기 전의 큐비트는 진폭을 가진 양자 상태이고, 측정한 뒤에는 측정 결과값 0 또는 측정 결과값 1 중 하나가 고전 비트에 저장돼요.

결과 돌려주기

측정 결과를 실행 결과로 보려면 Main이 그 값을 돌려줘야 해요.

operation Main(): bit { … return result; }

Main() 뒤의 : bit는 Main이 측정 결과값 하나를 돌려준다는 표시이고, return result;가 그 값을 돌려주는 줄이에요.
Qora는 Main이 돌려준 값만 실행 결과로 보여 줘요. 프로그램 안에서 측정만 하고 돌려주지 않은 값은 실행 결과에 나타나지 않아요.
VS Code의 Qora 확장에서 프로그램을 실행하면 같은 프로그램을 여러 번 실행하고, 돌려받은 값이 각각 몇 번 나왔는지 보여 줘요.

두 큐비트의 결과를 함께 돌려줄 때는 두 측정 결과값을 var result: bit[] = [first, second];처럼 비트 배열로 묶은 뒤, return AsInt(result);로 정수 하나로 읽어서 돌려줘요.
이때 Main() 뒤에는 정수를 돌려준다는 뜻으로 : int를 적어요.
왼쪽 자리를 q[0]으로 읽으므로 00은 0, 01은 1, 10은 2, 11은 3으로 나와요.

주석 쓰기

Qora에서는 //로 한 줄 주석을 쓸 수 있어요.
주석은 회로 실행에 영향을 주지 않으므로, 이 책의 Qora 실습 코드에서도 상태 변화를 적을 때 자주 사용할게요.

주석이 있는 Qora 코드

코드 줄마다 상태 변화를 적어보자

operation Main(): bit {
    // 큐비트 하나 준비
    use q = Qubit[1];

    // q[0]에 H 게이트 적용
    H(q[0]);

    // q[0] 측정
    var result: bit = M(q[0]);

    // 측정 결과값을 실행 결과로 돌려줌
    // 여러 번 실행하면 0과 1이 약 반반씩 나옴
    return result;
}
