양자컴퓨터가 계산하는 과정을 작은 예제로 살펴보겠습니다.
큐비트 하나를 준비한 뒤 상태를 바꾸고, 마지막에 측정해서 결과를 얻는 예제입니다.

지금은 ‘큐비트’나 ‘측정’이라는 말이 낯설어도 괜찮아요.
먼저 각 동작이 무엇을 뜻하는지 설명하고, 같은 동작을 Qora 코드로 옮겨보겠습니다.
코드에 나오는 기호와 명령도 한 줄씩 설명하므로, 프로그래밍을 처음 접하더라도 순서대로 읽으면 됩니다.

  1. 0과 1로 무엇을 표현할 수 있을까?
  2. 큐비트와 측정 결과 구별하기
  3. 큐비트 하나로 계산을 끝까지 따라가기

010과 1로 무엇을 표현할 수 있을까?

먼저 작은 표시등 하나를 생각해보겠습니다.
표시등이 꺼져 있으면 0, 켜져 있으면 1이라고 기록하기로 정하면, 두 상태를 숫자로 구별할 수 있습니다.

이렇게 0 또는 1 중 하나를 담는 정보의 단위를 비트(bit)라고 합니다.
표시등은 두 상태를 구별하는 예로 든 것이며, 실제 컴퓨터가 비트를 표시등으로 저장한다는 뜻은 아닙니다.
컴퓨터에서는 전자 회로 등의 구별 가능한 상태를 이용해 0과 1을 표현합니다.

비트 하나로 표현할 수 있는 값은 0과 1, 두 가지입니다.
그렇다면 비트 두 개를 함께 쓰면 어떨까요?
두 비트를 나란히 놓으면 00, 01, 10, 11이라는 네 가지 조합을 만들 수 있습니다.
비트가 많아질수록 가능한 조합도 늘어납니다.
글자나 사진도 정해진 규칙에 따라 이런 비트의 조합으로 표현합니다.

컴퓨터는 이렇게 표현한 값을 정해진 규칙에 따라 바꾸면서 계산합니다.
가장 간단한 예로 “0이면 1로, 1이면 0으로 바꾸기”를 생각할 수 있습니다.
0에서 시작해 이 동작을 한 번 적용하면 1이 되고, 한 번 더 적용하면 다시 0이 됩니다.

다음에는 큐비트에도 이와 비슷한 동작을 적용해보겠습니다.
무엇을 준비하고, 무엇이 바뀌며, 어떤 결과를 얻는지 구별하는 것이 이번 장의 목표입니다.

02큐비트와 측정 결과 구별하기

양자컴퓨터가 다루는 기본 정보 단위를 큐비트(qubit)라고 합니다.
실제 장치에서는 원자나 아주 작은 전기 회로 등을 이용해 큐비트를 만듭니다.
이런 대상의 상태와 변화를 설명하는 이론이 양자역학입니다.
이 책에서는 양자역학 전체를 배우기보다, 큐비트에 동작을 적용하면 무엇이 달라지는지부터 살펴봅니다.

큐비트를 이용해 계산한 뒤에는 결과를 읽어야 합니다.
이때 사용하는 동작이 측정입니다.
이 책에서 먼저 다룰 측정 방법은 큐비트 하나에서 0 또는 1을 얻는 방식입니다.
예를 들어 측정 결과가 1이라면, 그 1은 일반 컴퓨터에서도 저장하고 비교할 수 있는 비트 값입니다.

여기서 큐비트의 상태와 측정 결과는 구별해야 합니다.
같은 방법으로 측정하더라도, 큐비트가 어떤 상태에 있었는지에 따라 0과 1이 나올 확률이 달라질 수 있습니다.
반면에 측정 결과는 실제로 측정했을 때 얻은 0 또는 1입니다.
이 숫자 하나가 측정 전 상태의 모든 정보를 알려주는 것은 아닙니다.
또한 측정은 큐비트의 상태를 바꿀 수도 있습니다.

이번 장에서는 수식 대신 “측정하면 0이 나오는 상태”처럼 말로 상태를 설명하겠습니다.
상태를 수식으로 나타내는 방법은 3장에서 배우고, 그때부터 각 동작의 결과를 직접 계산합니다.

아래 예제는 장치의 오류가 없는 이상적인 경우를 기준으로 설명합니다.
“확실히 0이 나온다”는 표현은 이 조건에서 측정 결과가 0일 확률이 100%라는 뜻입니다.
실제 장치에서는 준비, 연산, 측정 과정의 오류로 다른 결과가 나올 수 있습니다.

03큐비트 하나로 계산을 끝까지 따라가기

이번 예제의 목표는 0이 나오는 상태로 큐비트를 준비한 뒤, 상태를 바꿔서 측정 결과 1을 얻는 것입니다.
준비, 상태 변경, 측정의 세 단계로 나누어 살펴보겠습니다.

0이 나오는 상태로 준비하기

먼저 큐비트 하나를 0이 확실히 나오는 상태로 준비합니다.
즉, 지금 측정하면 결과가 0이라는 뜻입니다.
다만 이번에는 바로 측정하지 않고, 다음 단계에서 상태를 바꾸겠습니다.

X 게이트로 상태 바꾸기

큐비트의 상태를 정해진 규칙에 따라 바꾸는 기본 연산을 양자 게이트라고 합니다.
지금 사용할 게이트의 이름은 X이며, “엑스 게이트”라고 읽습니다.

X는 0이 확실히 나오는 상태를 1이 확실히 나오는 상태로 바꿉니다.
반대로, 1이 확실히 나오는 상태에 적용하면 0이 확실히 나오는 상태가 됩니다.
앞에서 큐비트를 0이 나오는 상태로 준비했으므로, X를 한 번 적용한 뒤에는 1이 나오는 상태가 됩니다.

그렇다면 측정 결과 1을 이미 얻은 것일까요?
아직 측정한 것은 아닙니다.
측정할 대상의 상태를 바꾼 것입니다.

측정해서 결과 얻기

마지막으로 큐비트를 측정합니다.
앞 단계에서 1이 확실히 나오는 상태로 바꿨으므로, 측정 결과는 1입니다.

그림으로 따라가기

상태를 바꾸고, 결과를 얻기까지

지금 측정하면 0

미측정

아직 측정하지 않았습니다.

0이 나오는 상태로 준비했습니다. 지금은 상태만 준비했으며, 측정 결과를 얻은 것은 아닙니다.

원리를 설명하는 시각화이며 실제 프로그램 실행 결과는 아닙니다.
장면 선택은 설명을 다시 보는 동작이지, 측정을 취소하는 연산이 아닙니다. 장치 오류는 없다고 가정합니다.

이처럼 큐비트에 어떤 연산을 어떤 순서로 적용하는지 나타낸 것을 양자 회로라고 합니다.
여기서 회로를 작성한다는 것은 전자 부품을 직접 연결한다는 뜻이 아닙니다.
프로그램에 동작의 순서를 적으면, 실행 도구가 그 순서에 따라 계산을 진행합니다.

이 예제만 보면 앞에서 비트를 0에서 1로 바꾼 것과 비슷합니다.
실제로 이것만으로 양자컴퓨터의 계산 능력이나 속도의 차이를 보여줄 수는 없습니다.

04같은 동작을 Qora로 적어보기

이제 앞의 동작을 컴퓨터에 전달할 명령으로 적어보겠습니다.
컴퓨터에 시킬 일을 정해진 문법으로 표현하는 언어를 프로그래밍 언어라고 하며, 그 언어로 적은 명령문을 코드라고 합니다.
이 책에서는 양자 회로를 작성할 수 있는 프로그래밍 언어인 Qora를 사용합니다.

아래는 앞의 회로를 Qora로 작성한 전체 코드입니다.
큐비트를 준비하고, X를 적용하고, 측정한 다음 그 결과를 돌려줍니다.
이번 장에서는 각 줄의 뜻을 먼저 읽고, 실행 환경 설치와 직접 실행은 2장에서 진행하겠습니다.

Qora · 전체 예제
operation Main(): bit
{
    use q = Qubit[1];
    X(q[0]);
    var result: bit = M(q[0]);
    return result;
}

번호를 누르면 해당 설명으로 이동합니다.

01 큐비트 준비 02 X 적용 03 측정값 저장 04 반환

바깥 부분: 어디서 시작하고 무엇을 돌려줄까?

첫 줄의 operation은 양자 연산을 담을 수 있는 작업을 정의하는 말입니다.
그 뒤의 Main은 작업의 이름이며, 이 예제에서는 프로그램이 여기서 시작합니다.
이름 뒤의 ()가 비어 있는 것은 작업을 시작할 때 따로 전달받을 값이 없다는 뜻입니다.
마지막의 : bit는 작업을 마칠 때 비트 값 하나, 즉 0 또는 1을 돌려준다는 표시입니다.

여는 중괄호 {와 닫는 중괄호 } 사이에는 실제로 수행할 명령이 들어 있습니다.
이 예제에서는 위에서 아래로 한 줄씩 실행하며, 각 명령 끝의 세미콜론 ;은 명령이 끝나는 위치를 표시합니다.

큐비트 하나 준비하기

use q = Qubit[1];

이 명령은 큐비트 한 개를 준비하고, 그 큐비트가 들어 있는 묶음에 q라는 이름을 붙입니다.
Qubit[1]에서 대괄호 안의 1은 준비할 큐비트의 개수입니다.
새로 준비한 큐비트는 측정하면 0이 확실히 나오는 상태에서 시작합니다.

큐비트를 하나 준비했는데, 왜 q[1]이 아니라 q[0]이라고 쓸까요?
묶음 안의 큐비트를 가리킬 때는 위치 번호를 사용하며, Qora에서는 그 번호를 0부터 세기 때문입니다.
따라서 첫 번째 큐비트는 q[0]으로 가리킵니다.

Qubit[1]의 1은 개수이고, q[0]의 0은 위치 번호입니다.
여기의 0은 측정 결과를 뜻하는 것이 아니에요.

준비한 큐비트에 X 적용하기

X(q[0]);

이 명령은 q[0]에 X 게이트를 적용합니다.
X는 게이트의 이름이고, 괄호 안에는 그 게이트를 적용할 대상을 적습니다.
앞에서 이 큐비트를 0이 나오는 상태로 준비했으므로, 이 줄을 실행한 뒤에는 1이 나오는 상태가 됩니다.
상태가 바뀐 뒤에도 같은 큐비트를 q[0]으로 가리킵니다.

측정 결과에 이름 붙이기

var result: bit = M(q[0]);

이 줄에서는 먼저 오른쪽의 M(q[0])을 실행합니다.
M은 측정 명령이며, 괄호 안에 적힌 q[0]을 측정해서 0 또는 1을 얻습니다.
지금은 X를 적용해 1이 나오는 상태로 바꾼 뒤이므로, 측정 결과는 1입니다.

왼쪽의 var result: bit는 측정 결과를 저장할 변수 result를 만드는 부분입니다.
변수는 값을 저장하고 이름으로 다시 가리킬 때 사용합니다.
여기서는 측정으로 얻은 값을 보관합니다.
var는 변수를 만든다는 뜻이고, : bit는 저장할 값의 종류가 비트라는 표시입니다.
=는 오른쪽의 측정으로 얻은 값을 왼쪽 변수 result에 저장한다는 뜻입니다.
따라서 이 줄을 실행한 뒤에는 result에 1이 저장됩니다.

여기서 q[0]과 result는 서로 다릅니다.
q[0]은 게이트를 적용하고 측정한 큐비트이고, result는 측정 결과인 비트 값을 저장한 변수입니다.
result에 들어 있는 것은 1이라는 결과이지, 측정 전 큐비트의 상태 전체가 아닙니다.

실행 결과로 돌려주기

return result;

이미 M으로 측정했는데, 왜 return이 또 필요할까요?
측정값을 얻는 것과 그 값을 작업의 결과로 돌려주는 것은 서로 다른 일이기 때문입니다.

return은 현재 작업을 끝내고 값을 돌려주는 명령입니다.
여기서는 Main이 result에 저장된 1을 실행 도구에 돌려줍니다.
이렇게 돌려주는 값을 반환값이라고 하며, 실행 도구는 이 값을 받아 결과로 표시합니다.

Qora는 프로그램 안에서 측정한 값을 모두 자동으로 표시하지 않습니다.
이 예제에서 1을 실행 결과로 확인할 수 있는 이유는 마지막 줄에서 그 값을 반환했기 때문입니다.

이상적인 환경에서 예상하는 한 번의 실행 결과 · 실제 실행 화면이 아닌 설명용 표시 반환값: 1

전체 코드는 큐비트 준비 → X 적용 → 측정값 저장 → 반환의 순서로 실행됩니다.
앞에서 말로 설명한 회로에, 측정한 값을 저장하고 돌려주는 명령이 더해진 것입니다.

05결과는 0과 1인데, 무엇이 다를까?

그런데 0을 1로 바꾸는 일은 보통 컴퓨터도 할 수 있습니다.
그렇다면 양자컴퓨터는 무엇이 다를까요?
차이는 결과를 0과 1로 표시하는 방식이 아니라, 측정 전 큐비트의 상태와 그 상태를 바꾸는 연산에 있습니다.

비트 하나에 저장된 값은 0 또는 1입니다.
반면에 큐비트는 측정 결과가 0과 1 중 어느 쪽일지 확정할 수 없는 상태일 수도 있습니다.
이것은 단순히 “이미 0이나 1로 정해져 있지만 우리가 모르는 상태”와는 다릅니다.
아래 예제를 펼치면 그 차이가 드러나는 경우를 살펴볼 수 있습니다.

앞으로 풀어볼 질문: 같은 동작을 두 번 하면?

X와는 다른 연산인 H, 즉 “에이치 게이트”가 있습니다.
계산 규칙은 5장에서 자세히 다룹니다.
여기서는 0이 나오는 상태에 H를 한 번 적용한 경우와 두 번 적용한 경우의 결과를 먼저 비교하겠습니다.

각 경우마다 0이 나오는 상태로 새로 준비하며, 이상적인 조건을 가정합니다.
H를 두 번 적용하는 경우에는 두 게이트 사이에 측정하지 않습니다.
준비 뒤의 동작마지막 측정의 이론적 확률
바로 측정0이 100%
H 한 번 → 측정0이 50%, 1이 50%
H 두 번 → 측정0이 100%

두 번째 줄에서는 H를 한 번 적용한 뒤 측정합니다.
이때는 0과 1이 나올 확률이 각각 50%입니다.
반면에 세 번째 줄에서는 첫 번째 H 뒤에 측정하지 않고, H를 한 번 더 적용합니다.
그다음 측정하면 0이 확실히 나옵니다.
따라서 H를 “무작위로 0이나 1을 고르는 동작”으로 이해하면, 두 번 적용했을 때 왜 항상 0이 나오는지 설명할 수 없습니다.

이 표는 결과를 먼저 보여준 것이며, 아직 그 이유까지 설명한 것은 아닙니다.
3~5장에서 상태를 수식으로 표현하는 방법을 배운 뒤, 첫 번째 H와 두 번째 H가 각각 무엇을 바꾸는지 중간 계산까지 확인하겠습니다.

양자 회로를 이해하려면 측정 결과뿐 아니라, 측정 전에 어떤 상태였고 게이트가 그 상태를 어떻게 바꿨는지도 알아야 합니다.
이 책에서 수식을 배우는 이유는 이런 변화를 직접 계산하고 확인하기 위해서입니다.

06내 컴퓨터에서 어떻게 실행할까?

Qora 예제를 실행하기 위해 실제 양자컴퓨터를 준비할 필요는 없습니다.
일반 컴퓨터에서 양자 회로의 동작을 계산하는 프로그램인 시뮬레이터를 사용할 수 있기 때문입니다.

시뮬레이터는 각 연산을 적용했을 때 큐비트의 상태가 어떻게 바뀌는지 수학적으로 계산합니다.
측정 명령을 만나면 계산한 확률에 따라 결과를 생성합니다.
앞의 X 예제에서는 1이 나올 확률이 100%이므로 결과가 1입니다.
실제 큐비트를 조작하는 대신 그 동작을 수학으로 계산하는 것이므로, 노트북에서 예제를 실행한다고 노트북이 양자컴퓨터가 되는 것은 아닙니다.

코드를 적는 것부터 결과를 확인하기까지

  1. Qora 코드 작성
    어떤 큐비트에 어떤 동작을 적용할지 순서대로 적습니다.
  2. 코드 검사와 번역
    작성한 코드를 검사하고 다른 도구가 처리할 명령으로 바꾸는 프로그램을 컴파일러라고 합니다.
    Qora 컴파일러는 코드를 검사한 뒤, 양자 회로 명령을 적는 형식인 OpenQASM으로 번역합니다.
  3. 시뮬레이터에서 계산
    실행 도구가 번역된 명령을 시뮬레이터에 전달하면, 시뮬레이터가 회로의 동작을 계산하고 측정 결과를 생성합니다.
  4. 반환값 확인
    실행 도구가 Main의 반환값을 모아 보여줍니다.
    앞의 예제에서는 측정한 값을 그대로 반환하므로, 실행 결과에서 그 측정값을 확인할 수 있습니다.

즉, Qora는 동작을 적는 언어이고, 컴파일러는 그 코드를 번역하며, 시뮬레이터는 번역된 명령에 따라 계산합니다.
실제 설치와 실행은 2장에서 Qora의 VS Code 확장을 이용해 진행하겠습니다.

여러 번 실행할 때는 매번 처음 상태부터

측정 결과가 매번 같지 않은 회로도 있습니다.
이런 회로에서는 한 번 실행한 결과만으로 0과 1이 얼마나 자주 나오는지 알 수 없습니다.
그래서 “큐비트 준비 → 게이트 적용 → 측정 → 반환”을 여러 번 반복하고, 각 결과가 나온 횟수를 확인합니다.
이렇게 큐비트를 새로 준비해서 회로를 끝까지 실행하는 한 번을 샷(shot)이라고 합니다.

이것은 이미 측정한 큐비트를 그대로 다시 측정하는 것과 다릅니다.
매번 처음 상태로 준비한 뒤 같은 회로를 실행해야 동일한 조건에서 결과를 비교할 수 있습니다.
앞의 X 예제는 이상적인 조건에서 매번 1을 반환합니다.
반면에 0과 1이 나올 확률이 각각 50%인 회로는 100번 실행하더라도 결과가 반드시 50번씩 나뉘지는 않습니다.

07어떤 문제를 풀기 위한 계산일까?

앞의 예제에서는 0이 나오는 상태를 바꿔 1을 얻는 것이 목표였습니다.
더 복잡한 문제에서도 풀려는 문제를 먼저 정하고, 필요한 정보를 큐비트의 상태로 표현한 뒤 어떤 연산을 적용할지 설계합니다.
마지막에는 측정으로 얻은 결과를 문제의 답과 연결해 해석합니다.
이처럼 문제를 풀기 위한 절차를 알고리즘이라고 합니다.

양자 알고리즘은 양자 상태의 특성을 이용해 문제를 풉니다.
예를 들어 분자나 물질의 성질을 계산하는 것은 양자컴퓨팅의 중요한 연구 분야입니다.
다만 어떤 프로그램이든 양자컴퓨터에 옮기기만 하면 빨라지는 것은 아닙니다.
문제에 맞는 알고리즘이 필요하며, 계산에 필요한 장치의 크기와 연산의 정확도도 따져야 합니다.

큐비트가 많다고 가능한 모든 답을 한꺼번에 읽어낼 수 있는 것도 아닙니다.
측정에서 얻는 결과에는 제약이 있으므로, 원하는 정보를 얻으려면 측정 전에 적용할 연산을 적절히 설계해야 합니다.

이 책의 초판에서는 큐비트 한 개와 두 개로 만든 회로를 중심으로 상태, 기본 게이트, 측정을 배웁니다.
목표는 짧은 Qora 코드의 각 줄에서 무엇이 달라지고, 왜 그런 결과가 나오는지 직접 설명하는 것입니다.
이번 장에서는 그 첫 예제로 X를 적용하는 회로를 읽었습니다.

① 측정하기 전에 X를 두 번 적용하면 무엇이 나올까요?

처음에는 0이 나오는 상태입니다.
첫 번째 X를 적용하면 1이 나오는 상태가 되고, 두 번째 X를 적용하면 다시 0이 나오는 상태가 됩니다.
따라서 X를 두 번 적용한 뒤 측정하면, 이상적인 조건에서 결과는 0입니다. 

준비       : 0이 나오는 상태
첫 번째 X 후: 1이 나오는 상태
두 번째 X 후: 0이 나오는 상태
② X를 적용하면 q[0]이라는 이름도 q[1]로 바뀔까요?

아닙니다.
q[0]의 0은 큐비트 묶음에서의 위치 번호입니다.
X는 그 위치에 있는 큐비트의 상태를 바꿀 뿐, 다른 위치의 큐비트로 바꾸지 않습니다.
이 예제에는 큐비트가 하나뿐이므로 q[1]이라는 두 번째 큐비트 자체가 없습니다.

③ M으로 측정하는 것과 return으로 돌려주는 것은 같은 일일까요?

아닙니다.
M(q[0])은 큐비트를 측정해 비트 값을 얻는 동작입니다.
반면에 return result;는 변수에 저장된 값을 작업의 결과로 돌려주는 동작입니다.
이 예제에서는 측정으로 1을 얻어 변수에 저장한 다음, 그 값을 반환합니다.

이제 명령을 직접 실행해볼 차례

이번 장에서는 큐비트를 준비하고 X를 적용한 뒤 측정해서 1을 얻는 과정을 살펴봤습니다.
같은 동작을 Qora 코드로 읽으면서, 큐비트 자체와 측정값을 저장한 변수, 작업이 돌려주는 반환값도 구별했습니다.
