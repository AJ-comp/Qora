Qora로 처음 만나는 양자컴퓨팅 / 초판 개요와 목차

양자컴퓨팅과 프로그래밍을 처음 접하는 분을 위한 책입니다.
작은 양자 회로 하나를 놓고, 코드 한 줄이 무엇을 바꾸며 왜 그런 결과가 나오는지 차근차근 살펴보겠습니다.

이 책을 마치고 할 수 있는 일 짧은 Qora 프로그램을 읽고 직접 실행하면서, 각 단계에서 큐비트의 상태가 어떻게 바뀌고 어떤 측정 결과가 나오는지 설명하는 것이 목표입니다.

수학과 프로그래밍을 따로 공부하지 않은 분도 따라갈 수 있도록 구성합니다.
분수와 제곱근부터 복소수, 벡터와 행렬까지 실제 계산에 필요해지는 지점에서 소개합니다.
코드도 처음 등장한 줄부터 무엇을 뜻하는지 하나씩 설명하겠습니다.

초판에서 함께 살펴볼 범위

초판에서는 주로 큐비트 한 개와 두 개를 다룹니다.
X·H·Z·S·CNOT이라는 기본 게이트를 적용했을 때 무엇이 바뀌는지, 작은 예제에 실제 값을 넣어 계산합니다.
그 과정에서 측정, 초기화, 역연산을 함께 살펴보며 서로 어떤 차이가 있는지 구별하겠습니다.

계산으로 예측한 결과는 Qora 코드를 실행하여 확인합니다.
2장에서 첫 프로그램을 실행하고, 이후에도 새로운 개념을 배울 때마다 같은 도구로 작은 실험을 이어갑니다.

  • 양자컴퓨터와 시뮬레이터의 차이, 이 책에서 따라갈 작은 실험

2장. Qora로 첫 프로그램 실행하기

  • 실행 환경을 준비하고, 첫 프로그램의 모든 줄을 읽기
  • 큐비트 준비, 측정, 반환값과 실행 결과 연결하기

작성 예정

3장. 큐비트의 상태는 어떻게 적을까?

  • 상태와 측정 결과를 구별하고, 상태를 나타내는 기호 읽기
  • 기준 상태, 계수, 숫자를 나열한 벡터 표현을 하나씩 연결하기

2부. 큐비트 하나의 상태를 바꿔보자

작성 예정

4장. 확률진폭과 측정 확률

  • 실수 진폭으로 시작해 측정 확률과 전체 확률 계산하기
  • 반반 확률에 필요한 계수, 한 번의 결과와 반복 실행의 비율 구별하기

작성 예정

5장. X와 H는 상태를 어떻게 바꿀까?

  • 입력 진폭에 X와 H의 계산 규칙을 차례대로 적용하기
  • H를 두 번 적용하는 계산에서 강화와 상쇄 확인하기

작성 예정

6장. 부호와 복소수가 왜 중요할까?

  • Z로 진폭의 부호를 바꾸고 H로 그 차이 확인하기
  • 복소수의 크기와 확률을 계산하고, S로 허수 진폭 만들기

3부. 큐비트 두 개를 함께 읽어보자

작성 예정

7장. 텐서곱으로 공동 상태 만들기

  • 두 큐비트의 자리 순서와 네 가지 기준 상태 정하기
  • 텐서곱을 네 항으로 전개하고, 공통 부분을 묶는 계산 따라가기

작성 예정

8장. CNOT과 얽힘

  • 각 기준 상태에 CNOT을 적용하고, 중첩된 항의 변화 계산하기
  • H와 CNOT으로 벨 상태를 만들고, 각 큐비트의 상태로 분리할 수 있는지 살펴보기

작성 예정

9장. 측정하면 공동 상태는 어떻게 바뀔까?

  • 한 큐비트의 측정 결과를 0과 1로 나누어 계산하고 정규화하기
  • 중첩과 확률적 섞임, 측정 결과를 아는 경우와 모르는 경우 구별하기

4부. 배운 내용을 Qora 회로로 완성하기

작성 예정

10장. 되돌리기와 초기화는 무엇이 다를까?

  • 역연산과 측정 후 초기화를 같은 예제로 비교하기
  • CNOT을 되돌려 보조 큐비트를 정리하고, 남길 상태가 보존되는지 확인하기

작성 예정

11장. 작은 회로를 읽기 좋은 Qora 코드로 만들기

  • 큐비트와 측정값, bit와 bool, 조건문과 CNOT 구별하기
  • 반복되는 회로를 operation으로 묶고, 전달하는 값과 반환하는 값 이해하기

작성 예정

12장. 예측하고 실행하고 설명하기

  • H·Z의 간섭 실험과 벨 상태의 공동 측정 결과 확인하기
  • 측정 후 초기화와 CNOT 역연산을 직접 비교하고 계산과 실행 결과 설명하기

필요할 때 찾아보는 부록 (작성 예정)

  • 수학 다시 보기: 분수, 제곱, 제곱근, 복소수, 분배법칙
  • 기호 찾아보기: 상태 표기, 진폭, 텐서곱, 행렬
  • Qora 문법 찾아보기: 본문에서 사용한 문법
  • 실행 문제 해결: 설치, 오류 메시지, 결과가 표시되지 않는 경우
  • 연습문제 해설: 정답에 이르는 계산 과정

부록은 본문을 읽다가 계산이나 기호의 뜻을 다시 확인하고 싶을 때 참고할 수 있도록 구성합니다.

한 가지 질문을 끝까지 따라가는 방법

각 절에서는 같은 예제를 유지하면서 코드, 계산, 결과를 연결합니다.
새 기호는 뜻을 설명한 뒤 사용하고, 식을 전개하거나 묶을 때도 중간 단계를 보여드리겠습니다.
계산을 마치면 Qora로 실행하여, 예측한 확률과 실제로 얻은 결과의 비율을 비교합니다.

초판의 범위는 작은 양자 회로를 이해하고 직접 실행하는 데까지입니다.
본격적인 양자 알고리즘, 잡음과 오류 정정, 컴파일러 내부 구현과 자동 uncompute 알고리즘은 다루지 않습니다.
본문에 포함한 회로는 각 단계에서 무엇이 달라지는지 끝까지 설명하겠습니다.
