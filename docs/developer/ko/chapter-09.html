최종 HIR에서 최초 MIR로

의미 분석이 끝난 프로그램이 MIR 전체 프로그램으로 바뀌는 큰 흐름

이전 주제: 8장 목차전체 목차
다음: Callable lowering →

이 장에서는 최종 HIR이 MIR로 넘어가는 경계만 살펴봅니다.
개별 문장과 식을 어떻게 바꾸는지는 잠시 미뤄 두고, 프로그램 전체가 어떤 입력으로 들어와 어떤 결과로 나오는지 먼저 잡습니다.

예제로 사용할 프로그램

function Next(value: int): int
{
    return value + 1;
}

operation Work()
{
    var values: int[] = [0];
    use q = Qubit[1];

    values[0] = Next(values[0]);

    if (values[0] == 1)
    {
        X(q[0]);
    }

    H(q[0]);
}

의미 분석이 끝나면 HIR에는 Next와 Work라는 두 callable이 있습니다.
Work는 실행을 시작할 operation이고, Next는 그 안에서 호출하는 function입니다.

한눈에 보는 HIR → MIR 경계

최종 HIR compilation
├─ Next
└─ Work  ← 진입 operation
        │
        │ ToMir()
        ▼
최초 MIR snapshot
└─ MirProgram
   ├─ Next  (MirCallable)
   ├─ Work  (MirCallable)
   └─ EntryPoint = Work

핵심은 간단합니다.
ToMir()는 최종 HIR에서 callable을 하나씩 MIR callable로 바꾸고, 완성된 callable들을 MirProgram 하나로 묶습니다. 그런 다음 그 프로그램을 최초 MirSnapshot으로 감싸 반환합니다.

두 callable을 MirProgram으로 묶기

의미 분석이 끝난 최종 HIR에서 callable 목록을 앞에서부터 순회합니다.
이 예제에서는 Next를 먼저 바꾸고, 이어서 Work를 바꿉니다. 

HIR callable 목록
├─ Next
│  └─ callable lowering → MirCallable Next
└─ Work
   └─ callable lowering → MirCallable Work

완성된 MIR callable 목록
├─ MirCallable Next
└─ MirCallable Work

여기서 callable lowering은 함수나 operation 하나의 매개변수, 본문, block을 MIR 형태로 만드는 작업입니다.
그 내부 과정은 10장에서 별도로 살펴봅니다. 이 장에서는 두 결과가 목록에 모인다는 점만 기억하면 충분합니다.

모든 callable이 준비되면 MirProgram을 만듭니다.
이때 callable 목록뿐 아니라 어느 callable에서 실행을 시작할지도 함께 정하며, 예제의 진입점은 operation인 Work입니다.

최초 MirSnapshot이 되는 순간

MirProgram
├─ Callables
│  ├─ Next
│  └─ Work
└─ EntryPoint = Work
        │
        │ CreateLowered(program)
        ▼
MirSnapshot
├─ Program = 위 MirProgram
└─ Analyses = 위 Program 전용 분석 창구

MirProgram이 완성되면 MirSnapshot.CreateLowered(program)이 최초 MIR snapshot을 만듭니다.
반환된 snapshot은 방금 만든 MirProgram과 그 프로그램을 분석하는 Analyses를 함께 보관합니다.

정리

ToMir()
→ 의미 분석이 끝난 HIR 선택
→ Next와 Work를 각각 MirCallable로 변환
→ EntryPoint가 Work인 MirProgram 생성
→ 그 MirProgram과 Analyses를 가진 MirSnapshot 반환

이것이 HIR에서 MIR로 넘어가는 전체 경계입니다.
다음 장에서는 이 흐름 가운데 callable 하나를 변환하는 부분만 확대하여, Next와 Work가 각각 어떤 MirCallable이 되는지 살펴봅니다.
