Qora 컴파일러 개발자 매뉴얼

하나의 예제로 컴파일러의 큰 흐름을 이해하는 안내서

이 매뉴얼은 Qora 소스 하나가 HIR, MIR, MIR 분석으로 이어지는 큰 흐름을 설명합니다.
모든 helper와 생성자 인수를 나열하지 않고, 현재 단계에서 무엇을 받아 무엇을 만들며 다음 단계로 무엇을 넘기는지에 집중합니다.

현재 작성 범위 상세 본문은 9–17장까지 준비되어 있습니다.
나머지 장은 앞으로 다룰 주제를 확인할 수 있도록 목차만 유지합니다.
프로젝트 로드맵 현재 구현 상태와 다음 개발 항목은 Qora 로드맵에 정리되어 있습니다.

이 매뉴얼의 범위

이 개발자 매뉴얼은 아래 예제가 컴파일러의 각 단계를 지나며 어떤 모습으로 바뀌는지를 순서대로 보여줍니다.
장별 목차와 구현 함수 추적 링크도 모두 이 매뉴얼 안에서 이어집니다.

계속 사용할 예제

function Next(value: int): int
{
    return value + 1;
}

operation Work()
{
    var values: int[] = [0];
    use q = Qubit[1];

    values[0] = Next(values[0]);

    if (values[0] == 1)
    {
        X(q[0]);
    }

    H(q[0]);
}
Qora Source → HIR → MIR Callables → MirProgram → MirSnapshot → MIR Analyses

각 장은 이 흐름에서 한 가지 질문만 다룹니다.
예를 들어 13장은 큐비트 버전, 15장은 분기 합류, 17장은 CFG에만 집중합니다. 뒤 단계의 세부 내용은 필요한 장에 도착했을 때 설명합니다.
