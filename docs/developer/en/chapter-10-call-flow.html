LowerHirArtifact()

This function lowers each callable in the final HIR to MIR and packages the results into the initial MirSnapshot.
In this trace, the foreach loop processes Next and then Work.

The Qora program received by this function

function Next(value: int): int
{
    return value + 1;
}

operation Work()
{
    var values: int[] = [0];
    use q = Qubit[1];

    values[0] = Next(values[0]);

    if (values[0] == 1)
    {
        X(q[0]);
    }

    H(q[0]);
}

This function does not yet process individual statements such as array declarations or if statements.
It first reads two declarations from the program as the callables Next h6 and Work h44. The expression Next(values[0]) inside Work is not a third callable; it calls the existing Next h6 in the list.
Because Work is the operation from which execution can begin, EntryCallable is also Work h44.

Immediately before the call in the common example hirArtifact.Source.Program.Callables = [Next h6, Work h44]
hirArtifact.Source.Program.EntryCallable = Work h44
traceSink = null 
private static MirSnapshot LowerHirArtifact(
    HirSemanticArtifact hirArtifact,
    IMirLoweringTraceSink? traceSink)
{
    // hirArtifact contains the final HIR after semantic analysis.
    // Callables = [Next h6, Work h44]
    // EntryCallable = Work h44
    ArgumentNullException.ThrowIfNull(hirArtifact);

    var hirSnapshot = hirArtifact.Source;
    var hirProgram = hirSnapshot.Program;

    // Example value: hirEntryCallable = Work h44
    var hirEntryCallable = hirProgram.EntryCallable
        ?? throw new InvalidOperationException(
            "validated HIR must contain an operation before MIR lowering");

    // No callable has been lowered yet, so both values are empty.
    var mirCallables = new List<MirCallable>();
    MirCallable? mirEntryCallable = null;

    foreach (var hirCallable in hirProgram.Callables)
    {
        // First iteration:  hirCallable = Next h6
        // Second iteration: hirCallable = Work h44
        // A new lowerer is created for each iteration, so the two working states remain separate.
        var mirCallableLowerer = new HirCallableToMirLowerer(
            hirCallable,
            hirArtifact,
            traceSink);

        // First iteration result:  mirCallable = Next c6
        // Second iteration result: mirCallable = Work c44
        var mirCallable = mirCallableLowerer.LowerToMirCallable();

        // After the first iteration:  mirCallables = [Next c6]
        // After the second iteration: mirCallables = [Next c6, Work c44]
        mirCallables.Add(mirCallable);

        // Next is not the entry operation, so this is false in the first iteration.
        // Work is the same object as hirEntryCallable, so this is true in the second iteration.
        if (ReferenceEquals(hirCallable, hirEntryCallable))
            mirEntryCallable = mirCallable;
    }

    // Final result:
    // Callables  = [Next c6, Work c44]
    // EntryPoint = Work c44
    var mirProgram = new MirProgram(
        mirEntryCallable
            ?? throw new InvalidOperationException(
                "validated HIR entry callable must be lowered into MIR"),
        mirCallables);

    return MirSnapshot.CreateLowered(mirProgram);
}

Following the code in execution order

  1. Check the input. The callable list is [Next h6, Work h44], and the entry callable is Work h44.
  2. Process Next h6 in the first iteration. A new lowerer returns Next c6, producing the list [Next c6].
  3. Process Work h44 in the second iteration. A new lowerer returns Work c44, producing the list [Next c6, Work c44].
  4. Connect the entry point. The HIR object in the second iteration is the same object as EntryCallable, so mirEntryCallable = Work c44.
  5. Create the program and snapshot. The mirProgram containing the two callables and entry point is passed to MirSnapshot.CreateLowered(mirProgram).
Returned result MirSnapshot
Program.Callables = [Next c6, Work c44]
Program.EntryPoint = Work c44

HirCallableToMirLowerer(...) constructor

This constructor stores the target callable and final semantic information in a lowerer dedicated to one HIR callable, and prepares its MIR callable ID.
In the common example it runs once for Next h6 and once for Work h44. 

public HirCallableToMirLowerer(
    HirCallable hirCallable,
    HirSemanticArtifact hirArtifact,
    IMirLoweringTraceSink? traceSink)
{
    // First call:
    // hirCallable = Next h6
    // hirArtifact = final HIR artifact([Next h6, Work h44])
    // traceSink = null
    //
    // Second call:
    // hirCallable = Work h44
    // hirArtifact = final HIR artifact([Next h6, Work h44])
    // traceSink = null

    _hirCallable = hirCallable;
    _hirArtifact = hirArtifact;

    // First call:  hirCallable.Id.Value = 6  → _mirCallableId = c6
    // Second call: hirCallable.Id.Value = 44 → _mirCallableId = c44
    _mirCallableId = new MirCallableId(hirCallable.Id.Value);
    _traceSink = traceSink;
}

LowerClassicalParameter()

This function registers one classical HIR parameter as a MIR value and a MirClassicalParameter.
The run below processes value h0 from Next(value: int).

Actual arguments hirParameter = value h0
hirParameterSymbolId = SymbolId(value)
mirParameterOrigin = MirHirOrigin(HIR h0, source span of value)
requiredArrayLengths = null 
private void LowerClassicalParameter(
    HirParameter hirParameter,
    SymbolId hirParameterSymbolId,
    MirOrigin mirParameterOrigin,
    IReadOnlyDictionary<string, long>? requiredArrayLengths)
{
    /* value is an int, not an array.
    mirParameterType = MirType.Scalar(int) */
    var mirParameterType = hirParameter.IsArray
        ? MirType.Array(hirParameter.Type, hirParameter.RegisterSize)
        : MirType.Scalar(hirParameter.Type);

    /* The actual integer is not known yet.
    %v0 represents the int value that will be passed as value at call time.

    _mirValues
    └─ [0] MirValue %v0
       ├─ Id = v0
       ├─ Type = int
       └─ Origin = MirHirOrigin(value h0) */
    var mirParameterValue = CreateMirValue(
        mirParameterType,
        hirParameterSymbolId,
        mirParameterOrigin);

    /* Because this is a scalar, the result is (null, 0). */
    var (mirArrayStorage, minimumLength) =
        CreateMirParameterStorage(
            hirParameter,
            hirParameterSymbolId,
            mirParameterOrigin,
            requiredArrayLengths);

    /* SymbolId(value) ──▶ MirValueId v0 */
    _currentFlowState.CurrentMirValueByHirSymbolId[hirParameterSymbolId] = mirParameterValue.Id;

    /* mirArrayStorage is null, so Scalar is called.
    Name, Ownership, and Access are read directly from hirParameter. */
    var mirParameter = mirArrayStorage is null
        ? MirClassicalParameter.Scalar(
            hirParameter,
            mirParameterValue)
        : MirClassicalParameter.Array(
            hirParameter,
            mirParameterValue,
            mirArrayStorage,
            minimumLength);

    /* _mirParameters
    └─ [0] MirClassicalParameter value
       ├─ Value ──▶ _mirValues[0] (%v0)
       ├─ Storage = null
       ├─ Ownership = Borrowed
       ├─ Access = ReadOnly
       └─ MinimumLength = 0 */
    _mirParameters.Add(mirParameter);
}

CreateMirParameterStorage()

This function determines whether one classical parameter is a scalar or an array, then returns the required MirArrayStorage? and MinimumLength together.
It returns (null, 0) for a scalar. For an array, it creates new storage, computes the minimum length, and returns both values.

Processing Next(value: int)

Actual arguments hirParameter = value h0
hirParameterSymbolId = SymbolId of the value declaration
mirParameterOrigin = MirHirOrigin(HIR h0, source span of value)
requiredArrayLengths = null 
private (MirArrayStorage? Storage, int MinimumLength)
    CreateMirParameterStorage(
        HirParameter hirParameter,
        SymbolId hirParameterSymbolId,
        MirOrigin mirParameterOrigin,
        IReadOnlyDictionary<string, long>? requiredArrayLengths)
{
    /* value is a scalar, so this branch is selected.
    Return value = (Storage: null, MinimumLength: 0) */
    if (!hirParameter.IsArray) return (null, 0);

    /* The code below runs only for an array parameter.
    It creates new storage and records the link between the HIR symbol and MIR storage. */
    var mirArrayStorage = new MirArrayStorage(
        AllocateMirStorageId(),
        hirParameter.Name,
        mirParameterOrigin);
    _traceSink?.LinkStorage(
        hirParameterSymbolId,
        _mirCallableId,
        mirArrayStorage.Id);

    /* The default minimum length of an array parameter is 1.
    If the call contract records a greater length, that length is used. */
    var minimumLength = 1;
    if (requiredArrayLengths is not null
        && requiredArrayLengths.TryGetValue(
            hirParameter.Name,
            out var requiredLength))
    {
        if (requiredLength < 0 || requiredLength > int.MaxValue)
        {
            throw MirLoweringError(
                $"array parameter `{hirParameter.Name}` has invalid "
                + $"minimum length {requiredLength}");
        }

        minimumLength = Math.Max(minimumLength, (int)requiredLength);
    }

    return (mirArrayStorage, minimumLength);
}

LowerStatements()

This function traverses a list of HIR statements in order and passes each statement to LowerStatement().
The trace below completes Next first, then moves on to Work.

1. Lowering the Next body

function Next(value: int): int
{
    return value + 1;
}

hirStatements contains only return value + 1;, and the current block is b0 at entry.
Therefore, the outer for loop runs once. 

private void LowerStatements(IReadOnlyList<HirStatement> hirStatements)
{
    /* Actual input when lowering the Next body
    ├─ hirStatements = [return value + 1]
    ├─ hirStatements.Count = 1
    └─ _currentMirBlockBuilder = b0 */
    for (var hirStatementIndex = 0;
         hirStatementIndex < hirStatements.Count;
         hirStatementIndex++)
    {
        /* First iteration
        ├─ hirStatementIndex = 0
        ├─ hirStatements[0] = return value + 1
        └─ current block = b0

        b0 is open, so the null branch below does not run. */
        if (_currentMirBlockBuilder is null)
        {
            /* This runs only when an earlier statement ended the current path
               while statements remain. Remaining statements are not emitted as MIR;
               when traceSink is present, their declaration symbols are marked unreachable. */
            for (;
                 hirStatementIndex < hirStatements.Count;
                 hirStatementIndex++)
            {
                MarkUnreachableDeclarations(
                    hirStatements[hirStatementIndex]);
            }
            return;
        }

        /* Pass the return statement to LowerStatement().

        Before the call                 After the call
        current block = b0              b0.Terminator = return %v2
                                        current block = null */
        LowerStatement(hirStatements[hirStatementIndex]);
    }

    /* hirStatementIndex advances to 1.
       Because 1 < hirStatements.Count(1) is false, the loop ends.
       The function therefore exits with the current block set to null. */
}

While that call lowers the if, it passes the true body and empty false body back into the function. Thus, LowerStatements() runs three times in total while lowering Work. 

private void LowerStatements(IReadOnlyList<HirStatement> hirStatements)
{
    /* The same LowerStatements() body is entered three times while lowering Work.

    First call — top-level Work body
    ├─ hirStatements = [var values, use q, array assignment, if, H]
    ├─ starting block = b0
    ├─ 5 iterations
    └─ While lowering the if at index 3, the two calls below run.

       LowerStatement(if)
       └─ LowerIf()
          ├─ LowerScopedBranch(b1, true body)
          │  └─ Second call: LowerStatements([X(q[0])])
          └─ LowerScopedBranch(b2, false body)
             └─ Third call: LowerStatements([])

    Second call — true body of if
    ├─ hirStatements = [X(q[0])]
    ├─ starting block = b1
    └─ 1 iteration

    Third call — false body of if
    ├─ hirStatements = []
    ├─ starting block = b2
    └─ 0 iterations */
    for (var hirStatementIndex = 0;
         hirStatementIndex < hirStatements.Count;
         hirStatementIndex++)
    {
        /* The first and second calls have an open current block,
           so the null branch below does not run.

        First call
        ├─ current block = b0 when indices 0 through 3 begin
        └─ current block = b3 when index 4 begins

        Second call
        └─ current block = b1 when index 0 begins

        The third call has hirStatements.Count = 0,
        so the for-loop body does not run at all. */
        if (_currentMirBlockBuilder is null)
        {
            /* This runs only when an earlier statement ended the current path
               while statements remain. Remaining statements are not emitted as MIR;
               when traceSink is present, their declaration symbols are marked unreachable. */
            for (;
                 hirStatementIndex < hirStatements.Count;
                 hirStatementIndex++)
            {
                MarkUnreachableDeclarations(
                    hirStatements[hirStatementIndex]);
            }
            return;
        }

        /* Execution flow of the first call
        ├─ index 0: var              current block = b0 afterward
        ├─ index 1: use              current block = b0 afterward
        ├─ index 2: array assignment current block = b0 afterward
        ├─ index 3: pass if to LowerStatement().
        │
        │  Before this LowerStatement(if) call returns,
        │  the first LowerStatements() call pauses here.
        │
        │  Second call
        │  ├─ hirStatementIndex = 0
        │  ├─ Pass X(q[0]) to LowerStatement().
        │  └─ Return with current block = b1.
        │
        │  Third call
        │  ├─ hirStatements.Count = 0
        │  ├─ Do not execute the for-loop body.
        │  └─ Return with current block = b2.
        │
        │  After both calls return, LowerIf() connects b1 and b2 to b3.
        │  It sets the current block to b3, then returns to index 3 of the first call.
        └─ index 4: current block = b3 after lowering H */
        LowerStatement(hirStatements[hirStatementIndex]);
    }

    /* Return order
    1. The second call returns, leaving b1 current.
    2. The third call returns, leaving b2 current.
    3. The first call returns, leaving b3 current. */
}

LowerStatement()

This function identifies the kind of one HIR statement and forwards it to the lowering function responsible for that kind.
Its own work is limited to selecting exactly one branch of the switch below, calling that branch's helper once, and returning.

Every statement received by this function in the common example

function Next(value: int): int
{
    return value + 1;
}

operation Work()
{
    var values: int[] = [0];
    use q = Qubit[1];

    values[0] = Next(values[0]);

    if (values[0] == 1)
    {
        X(q[0]);
    }

    H(q[0]);
}

LowerStatement() does not receive the entire program above at once; each call receives exactly one statement.
In the common example it runs seven times: once for the return in Next and six times for statements in Work.
The switch below checks only the runtime HIR type of the current hirStatement argument. The order of the cases is not execution order, and exactly one matching case runs per call. 

1. Next: return value + 1

2. Work: var values = [0]
3. Work: use q = Qubit[1]
4. Work: values[0] = Next(values[0])
5. Work: if (values[0] == 1)
    6. True body: X(q[0])
7. Work: H(q[0])

Item 6, X(q[0]), is a nested execution that occurs while item 5, the if, is being lowered.
In contrast, Next(values[0]) inside assignment 4 is an expression, so it does not count as a separate LowerStatement() execution. 

private void LowerStatement(HirStatement hirStatement)
{
    switch (hirStatement)
    {
        // Selected by the use q statement in Work.
        case HirQubitDeclarationStatement hirQubitDeclaration:
            LowerQubitDeclaration(hirQubitDeclaration);
            return;

        // Selected by the var values statement in Work.
        case HirVariableDeclarationStatement hirDeclaration:
            LowerDeclaration(hirDeclaration);
            return;

        // Selected by the values[0] assignment in Work.
        case HirAssignmentStatement hirAssignment:
            LowerAssignment(hirAssignment);
            return;

        // Selected by the H call in Work.
        // The X call inside if selects the same branch while lowering the nested body.
        case HirCallStatement hirCallStatement:
            LowerStatementCall(hirCallStatement);
            return;

        // Selected by the if statement in Work.
        case HirIfStatement hirIf:
            LowerIf(hirIf);
            return;

        case HirForStatement hirFor:
            LowerFor(hirFor);
            return;

        case HirWhileStatement hirWhile:
            LowerWhile(hirWhile);
            return;

        case HirRepeatStatement hirRepeat:
            LowerRepeat(hirRepeat);
            return;

        // Selected by the return statement in Next.
        case HirReturnStatement hirReturn:
            LowerReturn(hirReturn);
            return;

        default:
            throw MirLoweringError(
                $"unsupported HIR statement {hirStatement.GetType().Name}");
    }
}

Following the code in execution order

  1. Inspect the runtime type of hirStatement. Each of the seven calls receives the HIR type corresponding to its current statement.
  2. Select one matching case. The actual statements and selected helpers are listed below.
  3. Return immediately after calling the helper. The return at the end of each case prevents the same statement from being processed by another case.
