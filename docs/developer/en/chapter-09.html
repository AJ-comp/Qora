From Final HIR to Initial MIR

The high-level flow that turns a semantically analyzed program into a complete MIR program

Previous topic: Chapter 8 indexAll chapters
Next: Callable lowering →

This chapter examines only the boundary where final HIR enters MIR.
It postpones the lowering of individual statements and expressions so that the input and output of the whole-program transformation are clear first.

Example program

function Next(value: int): int
{
    return value + 1;
}

operation Work()
{
    var values: int[] = [0];
    use q = Qubit[1];

    values[0] = Next(values[0]);

    if (values[0] == 1)
    {
        X(q[0]);
    }

    H(q[0]);
}

After semantic analysis, HIR contains two callables: Next and Work.
Work is the operation that starts execution, and Next is the function called from it.

HIR → MIR boundary at a glance

Final HIR compilation
├─ Next
└─ Work  ← entry operation
        │
        │ ToMir()
        ▼
Initial MIR snapshot
└─ MirProgram
   ├─ Next  (MirCallable)
   ├─ Work  (MirCallable)
   └─ EntryPoint = Work

The essential flow is simple.
ToMir() lowers each callable in final HIR to a MIR callable, collects the completed callables into one MirProgram, and returns that program wrapped in the initial MirSnapshot.

Collecting two callables into a MirProgram

The lowerer traverses the callable list in final HIR from beginning to end.
In this example it lowers Next first, followed by Work. 

HIR callable list
├─ Next
│  └─ callable lowering → MirCallable Next
└─ Work
   └─ callable lowering → MirCallable Work

Completed MIR callable list
├─ MirCallable Next
└─ MirCallable Work

Here, callable lowering converts the parameters, body, and blocks of one function or operation into MIR form.
Chapter 10 examines that internal process. For now, it is enough to note that both results are collected in one list.

Once all callables are ready, the compiler creates a MirProgram.
It records both the callable list and the callable where execution begins. In this example, the entry point is the Work operation.

Creating the initial MirSnapshot

MirProgram
├─ Callables
│  ├─ Next
│  └─ Work
└─ EntryPoint = Work
        │
        │ CreateLowered(program)
        ▼
MirSnapshot
├─ Program = MirProgram above
└─ Analyses = analysis entry point for that Program

When the MirProgram is complete, MirSnapshot.CreateLowered(program) creates the initial MIR snapshot.
The returned snapshot stores the newly created MirProgram together with the Analyses entry point that analyzes that exact program.

Summary

ToMir()
→ Select semantically analyzed HIR
→ Lower Next and Work into separate MirCallable objects
→ Create a MirProgram whose EntryPoint is Work
→ Return a MirSnapshot containing that MirProgram and its Analyses

This is the complete boundary from HIR to MIR.
The next chapter zooms in on the lowering of one callable and shows which MirCallable is produced for Next and Work.
