Qora Compiler Developer Manual

A guide to the compiler's complete flow through one example

This manual follows one Qora source program through HIR, MIR, and MIR analysis.
Rather than listing every helper and constructor argument, it focuses on what each stage receives, creates, and passes to the next stage.

Current coverage Detailed chapters are available for Chapters 9–17.
The remaining chapters stay in the index to show the topics planned for later coverage.
Project roadmap The current implementation status and upcoming work are listed in the Qora roadmap.

Scope of this manual

This developer manual shows, in order, how the example below changes as it passes through each compiler stage.
The chapter index and implementation call-trace links remain connected within this manual.

Running example

function Next(value: int): int
{
    return value + 1;
}

operation Work()
{
    var values: int[] = [0];
    use q = Qubit[1];

    values[0] = Next(values[0]);

    if (values[0] == 1)
    {
        X(q[0]);
    }

    H(q[0]);
}
Qora Source → HIR → MIR Callables → MirProgram → MirSnapshot → MIR Analyses

Each chapter answers one question from this flow.
For example, Chapter 13 focuses on qubit versions, Chapter 15 on branch joins, and Chapter 17 on the CFG. Details of later stages appear only when the corresponding chapter needs them.
