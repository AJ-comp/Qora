Qora コンパイラ開発者マニュアル

一つの例からコンパイラ全体の流れを理解するためのガイド

このマニュアルでは、一つの Qora ソースが HIR、MIR、MIR 解析へ進む全体の流れを説明します。
すべてのヘルパーやコンストラクタ引数を列挙するのではなく、各段階が何を受け取り、何を作り、次の段階へ何を渡すかに焦点を当てます。

現在の収録範囲 第9章から第17章までの詳細本文を用意しています。
その他の章は、今後扱うトピックを確認できるよう目次だけを残しています。
プロジェクトロードマップ 現在の実装状況と今後の開発項目は Qora ロードマップにまとめています。

このマニュアルの範囲

この開発者マニュアルでは、下の例がコンパイラの各段階を通るときにどのように変わるかを順に示します。
章別目次と実装関数の追跡リンクも、すべてこのマニュアル内でつながっています。

全章で使用する例

function Next(value: int): int
{
    return value + 1;
}

operation Work()
{
    var values: int[] = [0];
    use q = Qubit[1];

    values[0] = Next(values[0]);

    if (values[0] == 1)
    {
        X(q[0]);
    }

    H(q[0]);
}
Qora Source → HIR → MIR Callables → MirProgram → MirSnapshot → MIR Analyses

各章では、この流れに関する一つの問いだけを扱います。
たとえば第13章はキュービットのバージョン、第15章は分岐の合流、第17章は CFG に集中します。後段の詳細は、それを必要とする章で説明します。
