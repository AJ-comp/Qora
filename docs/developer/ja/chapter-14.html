Basic Block と Terminator

一つの if が b0 から b3 までに分かれる過程

← 前：キュービットバージョン全章目次
次：条件文 lowering →

MIR は if をネストした文ツリーのまま保持しません。
途切れず順番に実行される命令を Basic Block にまとめ、各 block の最後へ次の移動先を記録します。
共通例の if は b0、b1、b2、b3 の四つの block になります。

確認する Qora コード

function Next(value: int): int
{
    return value + 1;
}

operation Work()
{
    var values: int[] = [0];
    use q = Qubit[1];

    values[0] = Next(values[0]);

    if (values[0] == 1)
    {
        X(q[0]);
    }

    H(q[0]);
}

条件が true なら X を実行し、false なら何もしません。
どちらの経路を選んでも、if の後には H を実行する必要があります。
MIR はこの三つの区間を分け、制御フローを明示します。

四つの block の接続全体

                    ┌─ true ─▶ b1: X 実行 ─┐
b0: 条件計算と branch                       ├─▶ b3: H 実行と return
                    └─ false ▶ b2: 空経路 ─┘

b0 は条件を計算し、二つの経路から一つを選びます。
b1 は true の本文、b2 は false の経路を表します。
両方の経路は b3 で再び合流し、その後に共通して実行する H が続きます。

b0：条件を計算して経路を選ぶ

b0 には if より前に実行する配列宣言と更新も入りますが、ここでは最後の部分だけを見れば十分です。
MIR は values[0] == 1 を計算して %v10 を作り、branch がその値から次の block を決めます。 

b0
├─ %v10 = values[0] == 1
└─ branch %v10
   ├─ true  → b1
   └─ false → b2

block の最後で次の移動先を決める命令を Terminator と呼びます。
b0 の Terminator は二つの行き先を持つ branch です。
条件が true なら b1、false なら b2 へ移動するため、実行が二つに分かれます。

b1 と b2：各経路を実行して合流点へ進む

b1
├─ X(q0.v0) → q0.v1
└─ jump b3

b2
└─ jump b3

b1 は true 本文にあった X(q[0]) を実行します。
実行後に残る true 本文はないため、jump b3 で合流点へ移動します。

元のソースに else はありませんが、b2 は必要です。
条件が false のときに X を飛ばしてどこへ進むかを表す必要があるためです。
この経路に実行する本文はないので、jump b3 だけを持ちます。

jump も block を終える Terminator です。
branch は条件によって行き先を選びますが、jump は決められた一つの行き先へ移動します。

b3：経路を合流し、残りのコードを実行する

b3
├─ q0.v2 = phi(b1: q0.v1, b2: q0.v0)
├─ H(q0.v2) → q0.v3
└─ return

b1 と b2 はどちらも b3 へ到着します。
true 経路からは X を通った q0.v1、false 経路からは元のバージョン q0.v0 が来ます。
Phi は二つの入力を q0.v2 という一つの合流バージョンへまとめます。

元のコードの H(q[0]) は if の後にあるため、b3 で実行されます。
H が合流バージョン q0.v2 を受けて q0.v3 を作った後、Work に残る文がないため、MIR が追加した暗黙の return が block と callable を終えます。

MIR には両方の経路が残る

MIR 内には四つの block がすべて存在しますが、一回の実行は条件に合う一つの経路だけを通ります。
lowering は Next の呼び出し結果を事前計算しないため、次の二つの可能性を両方表現します。 

true 経路
b0 → b1 → b3 → return

false 経路
b0 → b2 → b3 → return

前章で確認したとおり、この正確な例を実行すると true 経路を選びます。
false 経路 b2 は実行結果を予測して削除された経路ではなく、lowering 段階が保持した制御フローの別の可能性です。

まとめ

一文で見る制御フロー b0 が branch で経路を選び、b1 と b2 が各経路を処理した後、jump で b3 に集まります。
b3 は経路別のキュービットバージョンを合流し、H を実行してから return で終わります。
