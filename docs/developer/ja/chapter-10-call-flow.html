Callable lowering の実装関数を追跡する

前章で準備した callable 専用 lowerer が、実際の MirCallable を作る C# 呼び出し経路

LowerHirArtifact()

選択した詳細フロー

最終 HIR artifact が MIR lowering に入る最初の関数 LowerHirArtifact() の詳細フローです。

LowerHirArtifact(...)

最終 HIR の callable を1つずつ MIR へ lower し、その結果を最初の MirSnapshot にまとめる関数です。
このトレースでは、foreach が Next、続いて Work を処理します。

まず関数全体を確認する

以下は、詳細フローを確認する LowerHirArtifact() の関数全体です。
まず HIR プログラムを読み取り、2つの callable を変換してから MirSnapshot を返す順序を確認します。
枠線と 詳細フローを見る バッジが付いた呼び出し部分を選択すると、LowerToMirCallable() の実行フローへ移動します。 

private static MirSnapshot LowerHirArtifact(
    HirSemanticArtifact hirArtifact,
    IMirLoweringTraceSink? traceSink)
{
    ArgumentNullException.ThrowIfNull(hirArtifact);

    var hirSnapshot = hirArtifact.Source;
    var hirProgram = hirSnapshot.Program;

    var hirEntryCallable = hirProgram.EntryCallable
        ?? throw new InvalidOperationException(
            "validated HIR must contain an operation before MIR lowering");

    var mirCallables = new List<MirCallable>();
    MirCallable? mirEntryCallable = null;

    foreach (var hirCallable in hirProgram.Callables)
    {
        var mirCallableLowerer = new HirCallableToMirLowerer(
            hirCallable,
            hirArtifact,
            traceSink);

        var mirCallable = mirCallableLowerer.LowerToMirCallable();
        mirCallables.Add(mirCallable);

        if (ReferenceEquals(hirCallable, hirEntryCallable))
            mirEntryCallable = mirCallable;
    }

    var mirProgram = new MirProgram(
        mirEntryCallable
            ?? throw new InvalidOperationException(
                "validated HIR entry callable must be lowered into MIR"),
        mirCallables);

    return MirSnapshot.CreateLowered(mirProgram);
}

public MirCallable LowerToMirCallable()
{
    var mirCallableOrigin = MirOriginFor(_hirCallable);
    var hirCallableSymbol = RequireHirDeclarationSymbol(
        _hirCallable.Id,
        $"callable `{_hirCallable.Name}`");
    var hirScopeGraph = _hirArtifact.Model.ScopeGraph
        ?? throw MirLoweringError(
            "the final HIR semantic model has no scope graph");
    var qualifiedSourceCallableName =
        hirScopeGraph.QualifiedName(hirCallableSymbol);

    _currentMirBlockBuilder = CreateMirBlock(mirCallableOrigin);

    LowerParameters();
    LowerStatements(_hirCallable.Body.Statements);

    CloseCallableBody(mirCallableOrigin);

    var mirBlocks = BuildMirBlocks();

    return new MirCallable(
        _mirCallableId,
        qualifiedSourceCallableName,
        _hirCallable.ReturnType is { } returns
            ? MirType.Scalar(returns)
            : null,
        _mirParameters,
        mirBlocks,
        mirCallableOrigin);
}

CloseCallableBody()

選択した詳細フロー

本体の処理後に残っている block を確認し、callable の戻り値の契約に応じた終了関数を呼び出すフローです。

LowerToMirCallable()→CloseCallableBody(mirCallableOrigin)

まず関数全体を確認します

終了する block がなければ、状態を変更せずにすぐに戻ります。
一方、未終了の block が残っている場合は、現在の callable が戻り値の型を宣言しているかどうかに応じて、終了方法を選択します。

operation Read(q: Qubit): bit { return M(q); } のように、operation も bool、int、bit、float、angle のいずれか1つの値を返せます。
測定した値自体は bit、r == 1 のような比較結果は bool です。
戻り値の型を宣言した場合、すべての経路で値を明示的に返す必要があります。型を省略した operation は void のままで、return; による早期終了が可能です。
ただし function の純粋性は変わらず、値を返す operation も function 内からは呼び出せません。

private void CloseCallableBody(MirOrigin mirCallableOrigin)
{
    if (_currentMirBlockBuilder is null)
    {
        return;
    }

    if (_hirCallable.ReturnType is not null)
    {
        MarkCurrentMirBlockUnreachable(
            MirOrigin.GeneratedFrom(
                mirCallableOrigin,
                "missing validated callable return"));
    }
    else
    {
        ReturnFromCurrentMirBlock(
            value: null,
            MirOrigin.GeneratedFrom(
                mirCallableOrigin,
                "implicit operation return"));
    }
}

以下では、共通例の Next を先に確認してから、Work に進みます。
それぞれのソースコードを確認し、CloseCallableBody() を呼び出したときに、どの分岐を通って状態がどう変わるかを追います。

1. Next では終了済みの状態を維持します

function Next(value: int): int
{
    return value + 1;
}

Next には return value + 1; があるため、本体の処理が終わると、b0 にはすでに return %v2 が記録されています。
この時点で、_currentMirBlockBuilder は null です。

したがって、CloseCallableBody() を呼び出すと、条件 _currentMirBlockBuilder is null が真になり、return; でこの補助関数をすぐに終了します。
Next の戻り値の型は int ですが、ReturnType の検査にも2つの終了関数の呼び出しにも進まないため、既存の状態が維持されます。

2. Work では残っている b3 を終了します

続いて、同じプログラムの Work を確認します。コード内の Next(values[0]) は、先ほど確認した Next の呼び出しです。

今回の CloseCallableBody() の呼び出しでは、_currentMirBlockBuilder が b3 を指しているため、条件 _currentMirBlockBuilder is null は偽になり、最初の return; をスキップします。
続いて、_hirCallable.ReturnType is not null を検査します。Work は戻り値の型を宣言していないため、ReturnType は null となり、else の ReturnFromCurrentMirBlock() を呼び出します。

ここでの ReturnType は、Work の戻り値の契約を表します。
block b3 自体や、Work の中で呼び出した Next の戻り値の型を検査する値ではありません。

パラメーター mirCallableOrigin には、Work h44 の出自情報が入ります。
この関数は、その情報を基に、暗黙の返却を追加する理由を記録します。

この章で確認した CloseCallableBody() は、本体処理後の現在の block を確認し、残っている block に必要な終了処理を選択します。

共通例の Next では、補助関数からすぐに戻り、終了済みの状態を維持しました。一方、Work では最初の return; をスキップし、未終了の b3 に値を返さない return を記録するフローを確認しました。

private void LowerParameters()
{
    var requiredArrayLengths =
        _hirArtifact.Model.RequiredArgLengths(_hirCallable.Id);

    for (var hirParameterIndex = 0;
         hirParameterIndex < _hirCallable.Parameters.Count;
         hirParameterIndex++)
    {
        var hirParameter =
            _hirCallable.Parameters[hirParameterIndex];

        var hirParameterSymbol = RequireHirDeclarationSymbol(
            hirParameter.Id,
            $"parameter `{hirParameter.Name}`");
        var mirParameterOrigin = MirOriginFor(hirParameter);

            hirParameterSymbol.Id);

                hirParameter,
                hirParameterSymbol.Id,

        }

            hirParameter,
            hirParameterSymbol.Id,
            mirParameterOrigin,
            requiredArrayLengths);
    }
}

private void LowerClassicalParameter(
    HirParameter hirParameter,
    SymbolId hirParameterSymbolId,
    MirOrigin mirParameterOrigin,
    IReadOnlyDictionary<string, long>? requiredArrayLengths)
{

        ? MirType.Array(hirParameter.Type, hirParameter.RegisterSize)
        : MirType.Scalar(hirParameter.Type);

        mirParameterType,
        hirParameterSymbolId,
        mirParameterOrigin);

            hirParameterSymbolId,
            mirParameterOrigin,

            hirParameter,
            mirParameterValue)

            hirParameter,
            mirParameterValue,
            mirArrayStorage,

}
