1. QoraLowering

문서 AST를 source-shaped HIR와 하나의 표현식 트리로 변환

패스 목차 2. SourceGraphLoader / ModuleLoader →

공개 QoraParser.Parse는 토큰, Qora 소유의 불변 파스 트리·AST 투영, 캡처된 트리 문자열, 구문 진단을 담은 SyntaxSnapshot에서 멈춥니다.
이 스냅샷은 Janglim AST를 보관하지 않으며, parser가 만든 변경 가능한 AST는 내부 SyntaxParseProduct가 HIR lowering 직전까지만 임시로 소유합니다.
whole-program 컴파일에서는 SourceGraphLoader가 이 임시 AST와 revision-qualified SourceDocumentRef를 QoraLowering에 전달하고, 변환이 끝나면 parser-owned AST를 공개 아티팩트에 남기지 않습니다.
QoraLowering은 파일 하나의 선언·문장·표현식을 Qora의 source-shaped HIR인 QProgram으로 옮겨 이후 단계가 Janglim 타입에 의존하지 않도록 합니다.

PASS SPECIFICATIONQoraLowering.Lower(AstSymbol?, SourceDocumentRef)
항목계약
입력 구조문서 하나의 Janglim AstSymbol과 exact SourceDocumentRef
성공 출력문서 하나의 Operations, Imports, namespace별 Opens를 담은 QProgram
출력 없음AST가 없거나 program nonterminal이 아니면 null; entry에서 이 상태가 발생하면 compiler가 QSEM040으로 중단
위치노드가 속한 문서를 포함하는 반열림 SourceSpan(Document, Start, End)
하지 않는 일import I/O, 문서 병합, 이름 해소, 타입·소유권·범위 검증, MIR·target 생성

2. 문장과 중첩 본문

lowering은 AST tag에 따라 전용 QStmt record를 선택하고, 중첩 본문을 소스 순서대로 재귀 변환합니다.
모든 문장은 LowerSpanned 한 지점을 통과하므로 키워드·괄호·중괄호·세미콜론을 포함한 문장 전체 범위가 같은 규칙으로 기록됩니다.

3. 표현식은 lowering에서 한 번 구조화

Janglim의 평평한 expression AST는 ExprTree가 연산자 우선순위를 적용해 하나의 QNode 트리로 바꿉니다.
기본 node는 숫자·literal·이름을 나타내는 QNumLit, QLit, QNameRef이며, 조합 node는 QUnary, QBinOp, QMember, QIndexNode, QCallNode입니다.
문법이 허용한 token을 일부만 소비한 경우에는 짧아진 트리를 조용히 반환하지 않고 내부 오류로 중단합니다.

QQubitArg(Reg, Index)

호출 인자 전체가 q[i + 1] 같은 index access이면 base 이름과 완전한 index QNode를 분리합니다.
후속 검증이 qubit인지 classical array element인지 판정합니다.

QTextArg(Tree)

전체 이름 q, 각도 식 pi / 2, 함수 호출 같은 나머지 인자를 트리로 보존합니다.
HasCall은 저장 boolean이 아니라 tree에서 파생됩니다.

QText(Tree)

선언·대입·return의 일반 오른쪽 값을 보존합니다.
유효한 함수 호출은 QCallNode로 남아 이후 resolver와 validator가 정확한 callable을 연결하고 검사합니다.

QCond(Tree)

비교·논리 연산과 중첩 호출을 같은 트리 체계로 보존합니다.
MeasureConditionLowering도 문자열을 다시 파싱하지 않고 이 트리를 직접 재작성합니다.

단독 측정 분류

선언이나 대입의 오른쪽 전체가 정확히 M(reference) 한 호출이고 reference가 단일 큐빗 이름 또는 register element이면 QMeasure를 만듭니다.
따라서 M(a)는 QMeasure(QNameRef("a"))가 되고, M(q[i])는 QMeasure(QIndexNode(QNameRef("q"), QNameRef("i")))가 됩니다.
반면에 M(q[i]) + 1, 다른 함수 호출, 산술식 target처럼 이 형태에 맞지 않는 값은 호출을 삭제하지 않고 일반 QNode 트리로 남겨 후속 단계가 진단하거나 해소합니다.

소스lowering 결과후속 처리
Apply(q[i + 1])QQubitArg("q", QBinOp("+", QNameRef("i"), QNumLit(1)))symbol·type·bounds 검증
Apply(pi / 2)QTextArg(QBinOp("/", QNameRef("pi"), QNumLit(2)))인자 타입 검증
var x = f(1) + 2;QText(QBinOp("+", QCallNode("f", ...), QNumLit(2)))함수 이름·signature·return type 해소
if (M(q[0]) == 1)QCond 안의 measurement QCallNodeMeasureConditionLowering이 선행 측정 문장과 bit 조건으로 분리
for i in 0..values.Count - 1From = QNumLit(0), To = QBinOp("-", QMember(...), QNumLit(1))bounds·MIR lowering에서 동일 tree 소비
단일 source of truth QText와 QCond이라는 이름은 남아 있지만 권위 데이터는 문자열이 아니라 Tree입니다.
printer와 backend가 필요한 spelling은 tree에서 만들기 때문에, bounds proof·resolver·emitter가 같은 식을 서로 다르게 재해석할 수 없습니다.

4. node identity와 SourceSpan

QProgram, callable, parameter, statement에는 안정적인 node Id가 있으며, 복사 패스는 필요한 경우 derivation을 별도로 기록합니다.
source location이 있는 callable·parameter·statement·import·open에는 현재 문서의 SourceDocumentRef가 포함된 SourceSpan을 붙입니다.
import 문서도 별도 document identity로 lowering되므로 위치를 null로 버리거나 entry 문서 offset으로 가장하지 않습니다.

노드IdSourceSpan 범위
QProgram있음별도 span 필드 없음
QOperation있음callable 이름 token
QParam있음parameter 이름 token
QStmt있음문장 전체 반열림 범위
QImport / QOpen없음지시문 전체 반열림 범위
QNode없음부모 statement의 span을 진단 문맥으로 사용

5. 다음 경계

SourceGraphLoader는 문서별 lowering 결과와 ImportGraph를 내부 LoadedSourceGraph로 묶습니다.
이때 공개 SyntaxSnapshot에는 이미 만들어 둔 불변 구문 투영만 저장하며, SyntaxParseProduct.LoweringAst는 문서별 QProgram을 만든 뒤 더 이상 유지하지 않습니다.
ModuleLoader는 이 prepared graph를 순수 병합해 통합 QProgram을 반환하고, QoraCompiler가 그 결과를 ImportsExpanded HIR milestone으로 발행합니다.
이후 MeasureConditionLowering과 Resolver가 구조 재작성과 이름 해소를 수행합니다.
type·signature·ownership·index 유효성, effect analysis, MIR, target 정책은 각각 자신의 입력이 준비된 후속 단계가 소유합니다. 

SourceGraphLoader
  ├─ parse: SyntaxParseProduct(SyntaxSnapshot, LoweringAst)
  ├─ publish: immutable SyntaxSnapshot only
  ├─ lower immediately: QoraLowering.Lower(LoweringAst, documentRef)
  ├─ discard parser-owned LoweringAst
  └─ ImportGraph + LoweredDocuments
       └─ ModuleLoader.Expand(loaded)
            └─ MeasureConditionLowering
                 └─ Resolver
                      └─ validation semantic artifact
                           └─ HirValidationOutcome(Accepted | Rejected)
