현재 권위 구조 · 실제 생산 아티팩트 · 아키텍처 설계 문서

권위 구조 생산 흐름 문서 지도 IR 패스 자동 uncomputation 양자 기초

이 문서는 과거의 소스 → AST → HIR → MIR 직선만 나열하지 않습니다.
현재 컴파일러가 실제로 발행하는 Compilation을 중심에 두고, 그 안에서 source·HIR·MIR·target·진단이 어떤 권위 객체로 묶이는지 먼저 보여줍니다.
필드와 불변 조건은 같은 아키텍처 문서군의 컴파일러 데이터시트에서 확인할 수 있습니다.

1. 현재 권위 구조

구조를 읽는 기준 AST는 공개 장기 산출물이 아닙니다.
parser가 만든 내부 SyntaxParseProduct.LoweringAst는 문서별 HIR lowering이 끝난 뒤 폐기되며, 공개 결과에는 불변 SyntaxSnapshot과 Qora 소유 HIR만 남습니다.

2. 실제 생산 흐름

경계실제 생산자생산 결과
문서 준비SourceGraphLoader → parser → AstToHirLoweringSourceSetSnapshot + 문서별 source-shaped HirProgram
통합 HIRModuleLoader → Resolver문서별 선언 subtree를 병합하고 호출 대상을 FQN과 CalleeId로 해소한 HIR
HIR 의미QoraValidator → Monomorphizer → EffectAnalysis검증 outcome과 의미 모델, size-specialized 구조, final effect-analysis artifact
MIRQoraMirLowering → MirAnalysisStoreexact final HIR artifact에 고정된 typed SSA/CFG MirSnapshot과 lazy 분석
TargetQasmBackend → MirOpenQasmLoweringtyped MirOpenQasmTargetProgram과 OpenQASM text artifact

파일 I/O와 문서별 파싱은 SourceGraphLoader가 담당합니다.
ModuleLoader는 준비된 문서별 HIR과 import graph만 받아 선언 subtree를 병합하며, 파일을 다시 읽거나 파싱하지 않습니다.
각 패스의 정확한 입력·출력·권위 경계는 데이터시트의 패스 표에서 확인할 수 있습니다.

3. 문서 지도

컴파일러 데이터시트 Compilation, SourceSet, HIR, MIR, target과 불변 조건의 기준 문서 IR 패스 문서 AST→HIR lowering과 문서 그래프 병합의 입력·출력·소유 경계 자동 uncomputation 코스 앤실라, 얽힘, qfree 계약, scheduler의 현재 미구현 경계를 잇는 16개 문서 양자 동작 기초 아키텍처 설계에서 사용하는 H 게이트와 진폭 변화를 별도 배경 문서로 확인 Namespace와 module 설계 다중 파일, namespace, open, scope graph와 이름 해소 규칙의 설계 기록

4. IR 패스 문서

1. AstToHirLowering 문서 AST를 source-shaped HIR 선언 트리로 바꾸는 경계 2. SourceGraphLoader와 ModuleLoader 문서 그래프 준비와 I/O 없는 순수 HIR 병합의 책임 분리

5. 자동 uncomputation 코스

현재 구현 경계 자동 uncomputation scheduler와 역연산 생성 패스는 현재 구현되어 있지 않습니다.
아래 문서는 현재 MIR이 제공하는 분석 재료와 향후 scheduler가 해결해야 할 판정 문제를 구분해서 읽는 설계 코스입니다.
1. 앤실라와 uncomputation 2. 컴파일러는 어떤 큐빗을 정리하는가 3. 상태를 읽는 법 — 상태벡터와 진폭 4. 곱 상태와 얽힌 상태 5. 곱에서 얽힘으로 — 프로그램 단계별 확인 6. 전역 위상과 상대 위상 7. 측정으로 위상 확인하기 8. 게이트는 상태벡터를 어떻게 바꾸는가 9. 청소의 계약과 qfree 10. Y·CY가 차단되는 이유 11. 주입기 — 문장 붙여넣기 기계 12. 루프와 호출 13. 담요 문제 — 질의 폭과 문장 폭 14. 원리적 한계와 보수적 거부 15. 왜 정적 컴파일인가 16. 언어 지형 속의 Qora
